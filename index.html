tandem rng

One generator, every language.

Tandem8x32 is a noncryptographic pseudorandom number generator with one specified stream that eighteen ports reproduce bit for bit, fast on CPUs and GPUs alike.

How it works

Eight 32-bit words

The state is two halves of four words. The hidden half runs a bijective clock and takes feedback from the exposed half. The exposed half is a Philox-shaped Feistel step whose multipliers come from the hidden half. Each step emits the 128 exposed bits.

Split, fork, purpose

A keyed seeding function starts every chunk of 32 steps, and eight chunks interleave into one 1024-bit row, so eight GPU lanes write one contiguous row. split(i) derives a child from the key and an index, fork(n) a batch from the current block, and purpose(u) a named sub-stream. A child costs at most one seeding.

Element i is draw i

Element i of a fill equals draw i, so any split across threads, ranks or GPUs reproduces a serial run. Bounded integers, normals and exponentials follow one shared appendix, so the ports agree on those too.
