# tandem-rng.github.io

The landing page of [tandem-rng](https://github.com/tandem-rng): plain HTML and CSS in `index.html`, no build step.
`.github/workflows/pages.yml` deploys `main` to GitHub Pages once the repository is public.
Every speed figure on the page cites the port repository it comes from.
